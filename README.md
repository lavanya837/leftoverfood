# 👨‍🍳 Leftover Food Chef (Zero-Waste Culinary Assistant)

An intelligent, interactive culinary chat application dedicated to transforming leftover food, fridge odds & ends, and wilting pantry scraps into delicious, zero-waste gourmet meals.

---

## 🌐 Live Website
Visit the live deployed site here: **https://lavanya837.github.io/leftoverfood/**

---

## ✨ Features

- **Fridge Inventory Basket:** Click to add leftover carbs, proteins, dairy, and crisper drawer veggies into your virtual kitchen basket, then whip up a tailored recipe with a single tap.
- **Smart Culinary AI Engine:**
  - Identifies leftover combinations (e.g. day-old rice, stale sourdough, cooked meats, wilting greens, overripe bananas, pasta).
  - Supplies precise cooking times, difficulty levels, and step-by-step instructions.
  - Shares practical zero-waste culinary hacks (e.g. freezing vegetable peelings for broth, using retrograded rice starches, reviving stale bread).
- **Interactive Cooking Modes:**
  - ⚡ *Under 15 Mins* (quick lunch / dinner)
  - 🥘 *One-Pan / Easy Cleanup* (fewer dishes)
  - 🧀 *Ultimate Comfort* (hearty and satisfying)
  - 🔥 *Crispy & Crunchy* (high-heat sears)
  - 🌱 *Fresh & Wholesome* (light and vegetable-forward)
- **Culinary Sound Effects:** Audio chimes synthesized via the Web Audio API on message send & receipt.
- **Theme & Utility:**
  - Dark / Light mode toggle
  - One-click **Copy Recipe** to clipboard
  - One-click **Print / Save as PDF**
  - Food safety tips (e.g. *Bacillus cereus* prevention in cooked rice, safe internal temperatures)
